수업 시간표

여기 적은 수업 시간에만 실험 페이지의 ‘결과 제출하기’가 열립니다. 비워 두면 시간 제한 없이 열립니다.
(실험 페이지에서 마감 시각을 따로 정해 두면 그 설정이 우선합니다 — 보강·결석생용.)

교시 시각 — 학교 종 시간(전 학년 공통)

채운 뒤 확인하고 교시 시각 저장을 누르세요.

분반별 수업 시간 — 예: 화3, 목5 (요일+교시, 쉼표로 구분)

구글 드라이브

수업자료와 학생 제출 파일을 선생님 드라이브에 저장합니다. Supabase 무료 저장소는 1GB라 과목 자료를 담기에 부족해서 드라이브를 씁니다.

불러오는 중…
1. OAuth 클라이언트 등록

Google Cloud 콘솔 → API 및 서비스 → 사용자 인증 정보에서 OAuth 클라이언트 ID(웹 애플리케이션)를 만든 뒤 값을 넣으세요. 승인된 리디렉션 URI에 아래 주소를 그대로 등록해야 합니다.

저장 후에는 다시 보여 주지 않습니다. 비워 두면 기존 값을 그대로 둡니다.

2. 구글 계정 연결

클라이언트를 저장한 뒤 연결하세요. 자료를 보관할 드라이브 계정으로 로그인합니다.

3. 저장 폴더

드라이브에 학교 › 학년도 › 학기 › 과목 › 분반 › 과제 순서로 폴더를 만들어 저장합니다.

학년도·학기는 제출 시점 날짜로 자동 계산합니다(3~7월 1학기, 8~12월 2학기, 1~2월은 전년도 2학기).

4. 과목별 폴더 이름

드라이브에 이미 있는 폴더 이름을 적어 두세요. 비워 두면 과목명 그대로 새 폴더가 생깁니다 (번호 없는 폴더가 따로 만들어지는 원인). 하위 폴더는 / 로 구분합니다 — 예: 01. 통합과학/통합과학2

매핑을 채우기 전에 올린 자료는 과목명 폴더에 남아 있습니다. 정리는 그 폴더를 매핑된 자리로 합칩니다 — 파일 주소는 바뀌지 않아 학생 링크는 그대로고, 빈 폴더만 휴지통으로 갑니다.

5. 공유 링크 회수

자료 파일은 이제 비공개로 두고 이 사이트를 거쳐서만 엽니다(교사 전용·공개 기간이 그때 적용됩니다). 예전에 올린 자료에는 “링크가 있는 모든 사용자 보기”가 걸려 있어 드라이브 주소만 알면 누구나 열립니다 — 아래 버튼으로 되돌리세요.

API 키

지금은 이 키를 쓰는 기능이 없습니다. 나중에 붙일 때를 위해 보관만 합니다.

키는 암호화 저장소(Vault)에 들어갑니다. DB에 원문이 없어서 백업 파일을 통째로 가져가도 값은 나오지 않습니다.

이 화면에서도 키를 다시 볼 수 없습니다 — 등록 여부와 끝 4자리만 표시됩니다. 값을 꺼낼 수 있는 건 서버(Edge Function)뿐이고, 관리자 계정으로도 못 꺼냅니다. 잊었으면 새 키를 발급해 덮어쓰세요.

학생에게 여는 기능에는 그대로 쓸 수 없습니다. 세 곳 모두 약관상 미성년자 대상 서비스 이용을 제한합니다. 교사가 직접 쓰는 도구로만 사용하세요.

최근 변경 내역

요금이 이상하면 여기서 내가 바꾼 게 맞는지 확인하세요.

관리자 계정

같은 과목 교과 선생님을 관리자로 초대합니다. 초대된 관리자는 수업 자료·학생·분반을 관리할 수 있지만, 관리자 계정을 만들거나 지울 수는 없습니다(소유자만 가능). 초대 시 이메일과 초기 비밀번호를 정해서 알려주세요.

학생 계정

아이디는 학생 이름(중복 시 분반 표기, 예: 김능곡B), 초기 비밀번호는 학번입니다. 학생이 처음 로그인하면 스스로 비밀번호를 바꿉니다.

· 이미 등록된 학생이면 새 계정을 만들지 않고 선택한 분반만 추가합니다(다른 학기·과목 겸수강 대응).
