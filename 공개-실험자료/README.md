## 걷어낸 것

- 이름·학번·분반 입력과 상단 식별 칩
- 사이트 로그인 정보 자동 주입(`window.__SITE_STUDENT__`)
- Supabase 주소·키, 서버 제출, 제출 기한 조회, 구글 시트 내보내기
- AI 검수(Google Gemini 전송) — 약관상 18세 미만 대상 서비스에 사용 불가
- 교사용 하드코딩 비밀번호와 우회 경로
- 외부 폰트(jsDelivr·Google Fonts) — 불러오면 학생 IP가 그 서버로 전송됨

## 확인된 것

- **네트워크 호출 0건.** `fetch`, `XMLHttpRequest`, `sendBeacon`, `WebSocket`, `EventSource`,
  외부 `src` 로딩 전부 0건. 스펙트럼에 남은 `http://www.w3.org/2000/svg` 4건은
  SVG 네임스페이스 식별자이지 요청이 아님.
- **외부 URL 0건**(이상기체), SVG 네임스페이스만(스펙트럼).
- 자바스크립트 문법 검사 통과(`node --check`).

## 동작 방식

파일 하나로 완결됩니다. 인터넷 없이도 열립니다. 진행 상황은 그 기기의 `localStorage`에만
저장되고, 마지막 단계에서 결과를 JSON 파일로 내려받아 학생이 직접 제출합니다.
파일명·내용에 이름·학번이 들어가지 않습니다.

## 배포

패들렛에 **파일로 첨부**하거나 링크로 거시면 됩니다. 호스팅이 필요 없습니다.

주의: 학생이 패들렛에 직접 글이나 파일을 올리게 하면 개인정보 수집이 발생할 수 있습니다
(교육부 2026학년도 학운위 심의 가이드 Q4·Q20). 교사가 올리고 학생은 보기만 하는 구조가 안전합니다.
